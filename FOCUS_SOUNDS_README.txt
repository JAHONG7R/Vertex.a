VERTEX — FOCUS SOUNDS UPDATE

This update adds a persistent Focus Sounds mixer to the existing Vertex project.

Included layers (all synthesized in-browser, not authentic field recordings):
Nature: rain, rain on roof, birdsong, forest ambience, whale-like calls, ocean waves, stream, waterfall, soft wind, rustling leaves, fireplace, night insects, distant thunder.
Focus textures: brown noise, pink noise, white noise, quiet café ambience, library room tone, fan noise.
Tone options: Binaural 10 Hz (200 Hz left / 210 Hz right; stereo headphones required) and 40 Hz low tone.

These are sound textures / approximations generated by Web Audio. The wildlife and environmental sounds are not recordings of actual animals or places.

Features:
- Multiple layers can play together
- Separate volume for each active layer and a master volume
- Mixer stays mounted while navigating between Vertex sections
- Mixer can be used while the Pomodoro page/timer is open
- Save and reload named presets (stored in this browser's localStorage)
- Stop all layers or collapse the floating panel

Important:
- Tap a sound button to start audio; browsers require a user gesture before playback.
- This implementation is designed to continue during internal Vertex navigation. It does not guarantee playback after the browser/app is closed or the phone suspends the page.
- Sound layers are synthesized in the browser; whale/bird sounds are not authentic wildlife recordings.
- Keep volume comfortable. Binaural audio is an optional listening effect, not a treatment or a proven way to improve focus.

Files changed:
- index.html
- script.js
- style.css

All other project files from Vertex_Real_Time_Reminders.zip are retained.


VOLUME UPDATE (2026-11-07)
- Master and per-layer sliders now allow up to 70% software gain.
- Default master level raised to 32%; new layers start at 22%.
- A dynamics compressor is placed on the master output to reduce clipping when mixing layers.
- The phone's physical media-volume control still determines final loudness. Do not raise it to an uncomfortable level; stop if listening becomes uncomfortable.

AUTHENTIC RECORDINGS STATUS
The existing nature and ambience layers in this package are synthesized Web Audio textures, not genuine field recordings. This update does NOT relabel them as real recordings. The project is ready for local recorded audio files, but authentic licensed WAV/MP3 assets have not been bundled because their source files and redistribution permissions must be verified before embedding them.


NATURAL-STYLE AUDIO UPDATE
--------------------------
Eight locally bundled stereo WAV loops are connected to the mixer. They are original procedural audio designs, not real-world field recordings. The remaining sound types continue to use the existing Web Audio synthesis.
